# Security and privacy

The analyzer runs completely offline and does not make network requests or send telemetry. It parses Garmin TCX XML using Python's standard library.

## Private fitness data

TCX files and generated JSON reports may include exercise dates, heart-rate metrics and other sensitive personal information. **Do not upload real workouts to public GitHub issues, tests, examples, or pull requests**. Redact timestamps, file names, activity identifiers and sensitive notes before sharing an example. Prefer a small synthetic reproducer generated by `tests/helpers.py`.

The repository deliberately ships only fabricated examples and test activities.

## Report bugs

Open a GitHub issue with a synthetic reproducer when possible. For security-sensitive findings, contact the repository maintainer privately through the GitHub profile's available channels before publishing exploit details. No separate security email address is claimed by this project.

## XML input

Treat TCX files as untrusted input. Avoid feeding arbitrarily large or attacker-supplied files into unattended batch jobs. The analyzer does not execute code from TCX contents and does not need elevated privileges.
